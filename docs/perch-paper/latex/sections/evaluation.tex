\paragraph{Method.} The reference run executes the built account, compiler,
Ed25519 verifier and recovery controller as contract Wasm in
soroban-sim~\selfcite{soroban-sim} with soroban-env-host
\fact{soroban-env-host-sim} on a local protocol-\fact{sim-protocol} ledger; a
native program and a WASI reactor run the same driver over the same pinned
bytes. Setup loads cost and configuration entries from a testnet fixture (ledger
\fact{fixture-ledger}; testnet now runs protocol \fact{testnet-protocol}) and
places the compiler and the Perch \fact{perch-deployed-account-version} policy
contracts at the addresses the account derives from its pins; a
\fact{registry-stub-bytes}-byte registry stub resolves the verifier name
\code{\fact{sim-verifier-name}} offline. Recovery uses real guardian signatures;
no zero-knowledge or passkey flow runs. After each command the driver
fingerprints every written entry's key, XDR and live-until value. Refusals in
enforcing simulation are not submitted, so an unchanged fingerprint says nothing
about fees for failed, submitted transactions.

\paragraph{RQ1: enforcement.} Every one of the \fact{run-commands} commands of

\paragraph{Threats to validity.} The build omits soroban-sim's exact-metering
host, so counts can differ from stellar-core metering, and memory and I/O are
not reported. Testnet resets periodically, and the testnet transactions
(Table~\ref{tab:tab-artifacts}) are not yet archived with their envelopes. The
testnet game ran from a patched branch. The comparator was run on one task, in a
recording-mode host. All local runs use host \fact{soroban-env-host-sim}, which
the host models were not tested against.
