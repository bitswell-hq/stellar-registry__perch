The function that decides is translated into Lean and proved about; the code
around it is tested. What is proved, in five lines:
\begin{itemize}[nosep,leftmargin=*]
\item Theorem~\ref{stmt:total-equivalence-of-the-evaluator}: the translation
  returns what the model returns on every input, without panic or loop.
\item Theorem~\ref{stmt:acceptance-implies-permission}: acceptance means an
  installed rule allows every call.
\item Theorem~\ref{stmt:attenuation-narrows-authority}: attenuation never widens
  a grant (modelled; not installable yet).
\item Theorem~\ref{stmt:cap-window-safety}: from an empty record, no window of
  $P$ ledgers holds more than the limit.
\item Theorem~\ref{stmt:grant-target-containment}: no grant, installed or
  derived, allows a call to the account or its adopted recovery contracts.
\end{itemize}
Not covered: the compiled Wasm, the account
