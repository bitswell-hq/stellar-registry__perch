\begin{statement}[Authorization-tree coverage.]\label{stmt:authorization-tree-coverage}
In the host model, every \code{require\_auth} that an account's entry satisfies is for a call that every rule set the modeled \code{\_\_check\_auth} checks allows, and \code{\_\_check\_auth} receives the entry's invocation tree in preorder, root first, so never an empty batch. The modeled account is an abstract program checking the stateless \code{allows}, not Perch's shell. The model was tested against soroban-env-host 29.0.1 and 30.0.0 on 95 traces it generated (35 named, 60 random) and on 39 traces (34 authorization, 5 storage) transcribed from 27 of the 74 tests in five host test files, agreeing on all 155 of their 213 cases that it expresses. It models CAP-0071 delegation between contract accounts; classic Stellar-account signers and delegates, \code{require\_auth} inside \code{\_\_check\_auth}, recording authorization, TTL and footprints are outside it, and this page's host, 29.0.2, was not tested.
