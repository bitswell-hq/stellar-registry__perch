One Rust source, crates/rule-eval, takes two paths. On the proof path, nightly rustc produces MIR, Charon turns it into LLBC, and Aeneas generates a Lean translation that CI regenerates and diffs. Lean's kernel checks the equivalence of that translation with the readable model and the theorems about both; all 940 exported theorems use only Lean's standard axioms. The specification (denotations, the document meaning and the host models) is trusted, and the host models are tested against the host. Perch's separate Lean package proves its canonical encoding injective.

On the shipping path, rustc 1.97.1 compiles the same source into the account's Wasm, where lower, lower_scoped and authorize run inside the tested account shell. Nothing checks that Wasm against the translation. Tests bridge the two paths: 57 Lean-generated document traces run through the real account entry points, and rule-core's vectors are replayed in Perch's CI.
