• (a) A lost guess: the signed tree is game.guess(0, guesser) with a child xlm.transfer of 1 XLM from the account to the game. Context 0 selects the game grant's guess rule and is allowed; context 1 selects the game grant's capped spend rule (2 XLM per 100 ledgers) and is allowed, charging 1 XLM.
  • (b) A winning guess: the tree is only game.guess, which the game grant's guess rule allows. The game then pays out its balance (3 XLM) under its own authority; nothing is charged to the game grant.
  • (c) A direct transfer of at most 2 XLM to any address, with no game call, selects the spend rule and is allowed at the pinned build, because each context is checked alone. A draft that checks exact entry roots would refuse it.

The auth payload names one installed rule per context (context_rule_ids); the fee payer may be another account.
