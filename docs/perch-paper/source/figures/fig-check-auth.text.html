  4. Refuse with ScopeEscalation (4) if a selected grant rule calls the recovery controller or its zero-knowledge adapter or pool. A completion leaves here and is decided by the controller's rcv_complete, which checks the exact approved bytes and the completion window.

  6. Resolve selected rule IDs to stored rules and spending records and convert contexts; refuse with ContextRuleNotFound (3000) or RuleEvalRefused (5).
  7. Run rule_eval::check_auth (pinned rule_eval::authorize), the step the theorems cover; a stale grant refuses with StaleScope (3), any other refusal with RuleEvalRefused (5).
  8. Hash the bound value with the selected rule IDs. Authenticate each signer: an external signer through its verifier contract (a failure traps with ExternalVerificationFailed, 3003), a delegated signer through the host's delegate_auth, which does not bind rule IDs.
  9. Store each capped spending record that changed.
