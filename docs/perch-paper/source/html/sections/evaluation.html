Does the account enforce what the design says?

Perch's tests run {{fact:lean-doc-traces}} document traces, generated from rule-core's Lean model, through the natively compiled account and compare every verdict and spending record with the model. In the recorded run of {{ref:sec:simulation}}, each Perch verdict is the one the shop grant specifies. The two designs gave the same verdict on every request except the {{fact:sim-oz-percall-sends}} payments made after the owner removed spending_limit, leaving the per-call bound alone. A native run, a WASI build and this page give the same replies.
