This experiment runs the built account, document compiler, Ed25519 verifier and recovery controller as contract WebAssembly inside soroban-sim, itself a WASI reactor in a browser worker, on a local protocol-{{fact:sim-protocol}} ledger. No wallet, real credential, RPC request or network transaction is involved. Each control sends a JSON command to the Rust driver, and every result shown comes from the runtime, never from the page.

To follow {{ref:tab:tab-run}}, create the account and work through the four groups in order. Completion is allowed from {{fact:recovery-delay-ledgers}} ledgers after the second guardian approval, so advance {{fact:demo-advance-ledgers}} ledgers before completing. Group 4 calls the actual Guess the Number contract, whose secret is drawn from {{fact:game-secret-range}}, so a guess of {{fact:game-losing-guess}} always loses; its winning-number helper reads the simulator's storage and is a harness fixture, not a game method. Then change the inputs: another cap or window, other amounts, a missing or wrong credential, or a JSON command of your own.
