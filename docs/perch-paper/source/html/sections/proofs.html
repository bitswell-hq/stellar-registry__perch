The evaluator is about 2,400 lines of dependency-free, no_std Rust that forbids unsafe code, in a subset Aeneas can translate (no traits, closures or iterator adaptors; every loop a while over one slice). Rule-core's CI regenerates the translation and fails on any difference, and it pins the axioms of all 940 exported theorems, none beyond Lean's three standard ones (propext, Quot.sound, Classical.choice), so none uses sorry.
