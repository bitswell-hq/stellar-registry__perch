The Perch account is built with its committed infrastructure pins rewritten to the compiler, interpreter and spending-limit builds of the same run, so its bytes differ from a committed-pin build and from the testnet preview's. The three OpenZeppelin-side hashes equal oz-policy-builder's testnet records; built with stellar-cli 27.0.0, the account and spending_limit match after normalize-oz.py sets the CLI version string in their metadata to 27.1.0's. sim/README.md beside the page, and the vision paper's reproducibility record, list these hashes and a registry stub the page does not load.
