Everything in this section is proposed, not built.

We propose an agent runtime in which a root agent holds a Perch grant and hands child agents budgets from a delegation tree, where spending beneath any node stays within its allowance ({{ref:stmt:delegation-tree-budgets}}, a model result); an account entry point that installs attenuated grants; exact authorization-entry roots, now in draft ({{fact:exact-roots-prs}}); a recording front end that emits grant documents; Cedar as an authoring language; and a measurement of both designs with exact metering. The vision paper describes each.
