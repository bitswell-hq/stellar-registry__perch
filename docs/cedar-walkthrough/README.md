# Cedar walkthrough

`index.html` is the accepted self-contained portable edition of the Cedar field
guide. It includes official Cedar Wasm 4.14.0, the interactive lab, source pins,
and complete third-party notices (also provided in `THIRD_PARTY_NOTICES.txt`).
The `#perch` chapter describes a restricted offline prototype, not a deployed
integration or a proved compiler.

This publication preserves the generated portable artifact byte-for-byte. For
content updates, coordinate with the walkthrough's authoring source (`page.py`,
`styles.css`, `model.mjs`, `app.mjs`, and `build.mjs`) and replace this export after
regeneration; do not create a separately maintained narrative here. Source
revisions and primary references are in the page's glossary and sources chapter.
