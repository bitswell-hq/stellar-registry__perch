Proposed, not built: an agent runtime with delegated budgets, installable attenuated grants, exact entry roots, and a recording front end that writes grant documents.

In the proposed runtime, a root agent holds a Perch grant and hands child agents budgets from a delegation tree, where spending beneath any node stays within its allowance ({{ref:stmt:delegation-tree-budgets}}, a model result). An account entry point would install the attenuated grants that {{ref:sec:grants}} models. Exact authorization-entry roots are in draft ({{fact:exact-roots-prs}}). We also propose Cedar as an authoring language and a measurement of both designs with exact metering. The vision paper describes each.
